# Hosted Agent vs Secure Agent

## Hosted Agent
- Fully managed by Informatica
- Used for SaaS-to-SaaS integrations
- No infrastructure responsibility

## Secure Agent
- Installed in customer environment
- Used for on-prem and private cloud data
- Ensures data residency and security

## Interview Tip
Use Hosted Agent for cloud-native workloads, Secure Agent for regulated or on-prem data.
